Register EIA je spoľahlivý, ale nie úplný: stavby pod 10 000 m² hrubej podlažnej plochy v zastavanom území (1 000 m² mimo neho) a pod 200 parkovacích stojísk doň nejdú. Tú dieru čiastočne kryjú vyhlášky z tabúľ a staveniská z OSM.

STROM PO ZDROJOCH

Enviroportál — register EIA
  • zber celého registra (10 min) → 2 303 bratislavských do detailu (30 min) → eia_detaily/ lokálne
  • čistenie ocisti.py: 23 bodov mimo BA von, 129 plánov von, 126 líniových s príznakom, 49 duplicít zlúčených → 988 projektov
  • účel stavby typy.py → kategórie v paneli
  • výkresy nahlady3.py → nahlady/ (381 galérií, 1 038 obrázkov) → karta, záložka Dokumenty
  • tabuľky → bez-polohy.json, doplnit-polohu/zamery.csv → stránka Doplniť polohy
Stavebné úrady — úradné tabule 16 MČ + CUET
  • tabule_sledovac.py týždenne: RSS alebo HTML podľa systému MČ → tabule_zaznamy.json len lokálne
  • z PDF: druh rozhodnutia, názov stavby, stavebník (len firma), parcely + k. ú. → kataster → bod
  • sedí na zámer (IČO, parcela, 2 slová) → fáza doložená vyhláškou → karta, riadok Stav
  • nesedí → tabule-stavby.geojson → vrstva Vyhlášky stavebných úradov (zelený prstenec)
  • CUET aj cez obohat_mapu.py (142 doložených fáz z prvého zberu)
Mestský geoportál
  • adresné body (pozor: celé Slovensko) → oprav_polohy.py ulica v správnej MČ → poloha „stred ulice"
  • kataster C a E → parcely_test.py vsetky + parcely_zapis.py → poloha „parcely", 349 bodov
  • hranice MČ → mestske-casti.geojson → hranice, názvy, ťažiská pre body bez polohy, kontrola každého bodu
  • výšková regulácia 3 829 plôch → vyska.geojson → vrstva + riadok v karte
  • žiadosti o zmenu ÚPN 89 → upn-ziadosti.geojson → vrstva s kartou
  • podklad OSM (vektor), ortofoto → naživo z geoportálu
RPO a ÚPV
  • RPO + ručná tabuľka 17 skupín → skupiny.py → ocisti.py určí istotu → karta: „Skupina" / „sídli na adrese skupiny X · indícia"
  • WebRegistre ÚPV podľa majiteľa (415 majiteľov → 861 známok) → znamky_upv.py → znamky_priradenie.py → nazvy-obchodne.json → obchodný názov v karte (39), 132 kandidátov v nazvy-navrh.csv
OpenStreetMap
  • trasy MHD → mhd_osm.py, mhd_zmensi.py → mhd.geojson → vrstva Linky MHD
  • pomenované staveniská (77 v BA) → osm_staveniska.py: do 30 m od bodu → obchodný názov (11); rovnaké meno ako zámer bez polohy → poloha (14); bez zámeru → osm-staveniska.geojson → vrstva Staveniská z OpenStreetMap (53)
3D model LOD1 2021
  • ArcGIS Pro → lod1_export.py (S-JTSK → WGS 84, transformácia S_JTSK_To_ETRS_1989_3) → lod1_dlazdice.py → budovy/ 79 dlaždíc → vrstva 3D budovy, farba podľa výšky
  • von ide len pôdorys a výška; nič iné z modelu sa nepublikuje
Ľudia
  • Google formulár + hárok (komunita.json, zatiaľ prázdne) → vrstva Komunitné body, schválenie = stĺpec v hárku
  • ručné zápisy do nazvy-obchodne.json (River Park ↔ CPR) → obchodný názov
  • Doplniť polohy → zamery.csv → späť do zamery.geojson
  • bod pridaný v mape — zatiaľ ostáva v prehliadači, export cez stránku Dáta
