Pripojenie na GitHub

Appka zapisuje priamo do repozitára SamuelZenko/kto-stoji-za-projektom. Potrebuje tvoj osobný token — vytvor si ho sám a vlož sem, nikam inam sa neposiela.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → kto-stoji-za-projektom
  3. Permissions → Repository permissions → Contents: Read and write (nič iné)
  4. Skopíruj token (začína github_pat_) a vlož ho sem

Token ostáva v tomto prehliadači (localStorage). Na cudzom počítači ho po práci vymaž tlačidlom Odpojiť.
